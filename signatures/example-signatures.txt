# Example signature rules for wp-scan
# New format (pipe-separated): ruleId|severity|pattern|description
# Fields:
#  - ruleId: short identifier (e.g., SHELL_C99)
#  - severity: info|warning|high|error
#  - pattern: ERE used to match inside PHP files (grep -E)
#  - description: brief human-friendly description
# Lines beginning with '#' are comments. Legacy single-pattern lines (no pipes) are still supported.

SHELL_C99|high|C99Shell|Known C99-like web shell UI strings
EVAL_USE|warning|\beval\b|Use of eval() - high risk
BASE64_DECODE|warning|\bbase64_decode\b|Base64 decoding often used by loaders/stagers
SUSPICIOUS_FILENAME|info|suspicious\.php|Filename matched as suspicious
